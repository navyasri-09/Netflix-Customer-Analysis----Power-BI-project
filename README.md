# 🎬 Netflix Customer Churn Analysis Dashboard

## 📌 Project Overview
This project presents an interactive Power BI dashboard built using a Netflix Customer Churn dataset. The dashboard helps analyze customer behavior, subscription patterns, churn trends, and key business metrics through interactive visualizations.

The goal of this project is to transform raw customer data into meaningful insights that support data-driven decision-making.

---

## 🚀 Features

- Interactive Power BI Dashboard
- Customer Churn Analysis
- Subscription Plan Analysis
- Customer Segmentation
- KPI Cards for Key Metrics
- Dynamic Filters and Slicers
- Trend Analysis and Visual Reporting

---

## 📊 Dashboard Insights

The dashboard provides insights such as:

- Total Customers
- Active Customers
- Churned Customers
- Churn Rate (%)
- Subscription Type Distribution
- Customer Demographics Analysis
- Monthly/Yearly Trends
- Revenue and Customer Retention Metrics
